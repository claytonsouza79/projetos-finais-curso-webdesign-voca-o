# Projetos Finais — Web Design Vocação 2026-2

Página simples para apresentação dos projetos finais.

## Estrutura
- `index.html` — estrutura da página
- `style.css` — visual responsivo
- `script.js` — renderização, busca e filtro
- `data.js` — dados dos jovens, projetos e links

## Organização
1. **Top 11** — destaque solicitado.
2. **Demais projetos** — galeria com busca e filtro por turma.

Os dados foram organizados a partir do documento `Projetos_Finais_WEB_2026-2`.

## Ajustes da versão 2
- Top 11 agora apresenta uma justificativa curta do destaque de cada jovem/projeto.
- Projetos repetidos entre vários jovens foram consolidados como equipes/grupos.
- Péricles Lanches recebeu a indicação de **projeto real no ar**, conforme informação fornecida pelo professor: o jovem negociou o desenvolvimento com o proprietário da lanchonete durante o curso.

## V3 — revisão da Seção 2
A Seção 2 foi reorganizada a partir da tabela `Markdown colado.md`.

Regra utilizada: quando o mesmo **link executável** aparece associado a vários jovens, o trabalho foi consolidado como **um grupo/equipe**, preservando os integrantes e os repositórios individuais.

Todos os links executáveis encontrados na tabela foram transformados em botões/links clicáveis. O AfroCachos usa o endereço atualizado informado pelo professor: `https://afrocachos.vercel.app`.
